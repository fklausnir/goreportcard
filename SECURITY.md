## Reporting a Vulnerability

Please report suspected vulnerabilities privately using this repository's GitHub
**Report a vulnerability** feature in the **Security** tab. Do **not** open a
public issue, discussion, or pull request for security-sensitive reports.

After a report is submitted, we will:

- acknowledge receipt within **3 business days**;
- provide an initial triage/update within **7 business days**;
- keep you informed of material status changes until the issue is resolved or
  determined not to be a vulnerability.

If the report is validated, we will work on a fix and coordinate disclosure with
you when appropriate. If the report is declined, we will let you know why it
was not accepted.
